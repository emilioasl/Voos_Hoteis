Conectar ao seu robô

O site conversa com o seu PC por um repositório privado do GitHub. Cole aqui um token que só tenha acesso a esse repositório. Ele fica guardado só neste navegador.

📲 Não pedir o token de novo
Toque em Abrir link com acesso e, na página que abrir, use Adicionar à Tela de Início (iPhone: botão compartilhar · Android: menu ⋮). O ícone já entra conectado. Não mande esse link para ninguém — ele leva o token junto.
📝 Link para outra pessoa pedir hotéis
Abre o site direto no pop-up 📝 Solicitação, já com a chave (ex.: para sua esposa pedir hotéis e datas sem você). Mande só para quem você confia — com a chave dá para mexer no robô.
